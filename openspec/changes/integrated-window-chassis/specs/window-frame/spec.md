# Spec Delta

## Purpose

定义 `032player-rs` 桌面客户端「一体外壳画布（Chrome 外框）」窗口框架与自定义顶壳的外观层次、窗口控制交互、导航与搜索入口收敛、全场景布局适配及多平台降级行为规范。

## ADDED Requirements

### Requirement: 窗口采用一体外壳画布框架并与主题实时联动
客户端 SHALL 取消系统默认标题栏，由顶部外壳栏、左侧导航栏与底部播放条共同构成连续的 `Theme.chrome` 外框；主内容区（`Theme.bg`）与右侧「正在播放」栏（`Theme.panel`）以圆角内嵌画布形式承载于外框之中，整体外框边线、圆角、阴影与失焦态随主题和窗口状态实时同步。

#### Scenario: 常规窗口在深色与浅色主题下呈现完整一体外壳
- **WHEN** 客户端处于已登录的常规非最大化窗口状态，用户在 032 Dark、032 Light 与跟随系统主题间切换
- **THEN** 窗口顶部外壳栏、左侧导航栏与底部播放条保持连续一致的 `Theme.chrome` 底色且之间无冗余分隔线；主内容区与右侧「正在播放」栏各自呈现 `10px` 圆角、`1px` `Theme.border` 描边与 `8px` 间距；窗口外框边线与系统边框颜色同步切换为当前主题配色

#### Scenario: 窗口最大化时自动消除外圆角与外框边线并保持内嵌画布节奏
- **WHEN** 用户将窗口最大化（通过双击顶壳空白区、点击最大化按钮或系统快捷键）
- **THEN** 窗口完整贴合当前显示器工作区且不遮挡任务栏，窗口最外缘取消圆角与外投影、顶壳最大化图标切换为还原图标，同时内嵌主画布与右栏画布仍保持 `10px` 圆角与外框呼吸边距

#### Scenario: 窗口失焦时降低顶壳与外框视觉存在感
- **WHEN** 客户端窗口失去操作系统前台焦点或重新获得焦点
- **THEN** 失焦时窗口外框边线、顶壳品牌标、导航控件与窗口控制按钮柔和降暗；重新聚焦后立即恢复正常对比度

### Requirement: 自定义顶壳提供完整的原生级窗口操控与关闭到托盘兼容
客户端 SHALL 通过自定义顶壳与窗口边缘支持拖动、双击最大化、八向缩放、最小化、最大化/还原及关闭操作，并完整兼容现有的关闭到托盘与窗口几何记忆行为。

#### Scenario: 拖动顶壳空白区与双击切换最大化
- **WHEN** 用户在顶壳非交互空白区域按下鼠标左键拖动，或双击该空白区域
- **THEN** 拖动触发系统窗口移动并支持 Windows 边缘贴边（Aero Snap）；双击在常规与最大化状态之间切换，且不误触搜索框、返回键或右侧按钮

#### Scenario: 鼠标靠近非最大化窗口边缘与四角可自由缩放
- **WHEN** 窗口处于常规非最大化状态，用户将鼠标移至窗口四边或四角并按住拖动
- **THEN** 鼠标光标切换为对应方向的缩放光标并平稳调整窗口尺寸，同时遵守窗口最小尺寸约束（`960x600`）

#### Scenario: 自定义关闭按钮遵守关闭到托盘与窗口状态持久化
- **WHEN** 用户点击顶壳右上角关闭按钮
- **THEN** 若已启用「关闭时最小化到托盘」且系统托盘可用，客户端先记录当前窗口尺寸与位置再隐藏到托盘；否则先记录窗口状态并正常退出应用，与系统关闭请求行为完全一致

#### Scenario: 顶壳最大化与最小化按钮状态准确响应外部窗口变化
- **WHEN** 用户通过系统快捷键（如 `Win+Up`、`Win+Down`）、任务栏操作或双击顶壳改变窗口最大化/还原状态
- **THEN** 顶壳最大化/还原按钮的图标与点击目标始终与真实窗口状态一致

### Requirement: 顶壳收敛品牌标、返回导航、全局搜索与右栏开关入口
客户端 SHALL 将核心全局外壳操作收敛至顶壳，消除详情页悬浮返回钮、侧栏/搜索页双搜索框以及窄屏悬浮右栏钮造成的元素冗余与遮挡。

#### Scenario: 顶壳左侧统一承载返回导航与轻量路径提示
- **WHEN** 客户端处于已登录状态并从列表页进入专辑、艺人、歌单、作品、系列、每日推荐、其他版本或搜索页
- **THEN** 顶壳左侧 `<` 返回按钮变为可用状态并展示轻量路径提示（如 `专辑 / <名称>`），点击可按既有历史栈返回并恢复原滚动位置；无返回历史时按钮保持置灰不可点；详情页内容区左上角不再叠加悬浮圆形返回按钮

#### Scenario: 顶壳居中全局搜索框取代侧栏与搜索页重复输入框
- **WHEN** 用户在任意已登录页面点击顶壳居中搜索槽或按下「搜索」快捷键（默认 `Ctrl+K`）
- **THEN** 顶壳搜索输入框直接获得焦点并高亮聚焦边框；用户输入关键词并防抖或按回车后自动进入/刷新搜索结果页，清空按钮可一键重置输入；左侧栏不再展示独立的「搜索曲库」按钮，搜索结果页内不再重复渲染第二套搜索输入框

#### Scenario: 顶壳右侧提供统一右栏开关并在窄屏取代悬浮入口
- **WHEN** 用户在宽屏或窄屏（`<= 1280px`）下点击顶壳窗口按钮左侧的「正在播放栏开关」图标
- **THEN** 宽屏下展开或收起右侧停靠画布（收起时主画布自然铺满右侧且底部播放条恢复左侧封面），窄屏下展开或收起带圆角与投影的右侧浮层抽屉；按钮高亮状态与右栏开关状态同步，窄屏主区右上角不再出现漂浮的圆形歌词入口按钮

### Requirement: 全屏舞台、窄屏与登录态保持统一外壳语言与零遮挡
客户端 SHALL 在全屏播放器、窄窗口和未登录/自动恢复会话状态下分别裁剪顶壳元素，确保画布圆角与窗口控制按钮在任何状态下都不与页面内容冲突。

#### Scenario: 全屏播放器下顶壳切换为舞台收起模式
- **WHEN** 用户打开全屏播放器覆盖层
- **THEN** 顶壳隐藏全局搜索框与右栏开关，左侧切换为「收起全屏」按钮与当前播放曲目提示，右侧保留最小化/最大化/关闭按钮；下方以单块 `Theme.stage` 圆角画布承载全屏舞台并保留底部播放条，窗口按钮不遮挡歌词与队列卡片

#### Scenario: 窄窗口下左栏收为图标条且顶壳不溢出
- **WHEN** 窗口逻辑宽度收缩至 `<= 1280px`（含最小宽度 `960px`）
- **THEN** 顶壳左侧省略应用文字仅保留小图标与返回键，中间搜索槽按剩余空间弹性收缩，右侧保持右栏开关与窗口控制按钮完整可点且不发生重叠或截断

#### Scenario: 登录页与启动恢复态展示极简顶壳与单画布
- **WHEN** 客户端处于未登录登录页或启动自动恢复凭据状态
- **THEN** 顶壳仅保留左侧品牌标与右侧窗口控制按钮（不显示返回键、搜索框与右栏开关），下方以带外框留白的圆角单画布承载登录表单或连接提示，并全程支持拖动、缩放与关闭

### Requirement: Windows 11 原生融合与跨平台安全降级
客户端 SHALL 在 Windows 11 上将无边框窗口与系统桌面合成器自然融合，在 Windows 10 与 Linux/macOS 上保持可拖动、可缩放且边界清晰的降级表现，且不破坏弹窗交互与无显示环境的构建测试能力。

#### Scenario: Windows 11 同步原生圆角、外框着色与窗口阴影
- **WHEN** 客户端运行于 Windows 11 桌面环境并在常规与最大化、深色与浅色主题间切换
- **THEN** 常规状态下窗口具备 Windows 11 原生圆角、与当前主题 `Theme.border` 一致的外框颜色以及窗口阴影；最大化时取消圆角，且不引入 `unsafe` Win32 子类化钩子

#### Scenario: 弹窗打开时仍可安全操控窗口外壳
- **WHEN** 新建/编辑歌单、删除确认、查看曲目信息、歌词搜索或选择艺术家等模态弹窗打开
- **THEN** 弹窗遮罩覆盖顶壳下方的内容区域，顶壳拖动与窗口控制按钮仍可正常响应，且 `Esc` 关闭弹窗的原有行为保持不变
