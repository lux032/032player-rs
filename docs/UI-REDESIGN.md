# 界面改版计划（v3 Editorial）

2026-11-06 定稿。主画布按宽屏 Windows 桌面（3452x1781、150% 缩放、窗口最大化，约 **2300x1190 逻辑像素**）。
目标是解决当时界面「空白多、布局松散、元素细碎」的问题。功能和信息架构不变，外壳和各页面的排布、尺度、质感重做。

## 已确认的决策

1. **范围**：外壳可以重构，导航项、所有功能、信息架构不变，首页模块和顺序不变。
2. **画布**：以 2300x1190 为主；1920x1080、1600x900 也要好看；1280x800 只要求不崩、不截断。
3. **外壳**：三栏。左导航（默认 248）+ 主内容 + 右侧「正在播放」栏（默认 420）；底部播放条横贯全宽。
4. **宽屏铺排**：封面网格按宽度加列；列表类内容分栏，单行不超过约 720；主推横幅贴边铺满主内容宽度。
5. **视觉**：Editorial 风格（参考 Roon），深色为主，紫色 accent。根据使用反馈，页头改为克制的标题比例（宽屏横幅 64、专辑名 72，字重 600），不再沿用最初的超大粗体。
6. **不做封面氛围**：不做封面取色、不做模糊封面背景，全部用中性表面。试看过两版氛围效果后决定去掉。
7. **作品海报**一律 2:3；**OP / ED 悬停弹窗**的交互保持现状，只换样式。
8. 亮色主题保留，按下面的 token 对应关系给出，不单独出设计稿。

## 与现状的行为差异（实现前必须清楚）

| # | 现状 | 改版后 |
|---|------|--------|
| D1 | 侧栏底部在窗口高度 ≥ 880 时显示当前封面（`sidebar.show-cover`） | 去掉。当前封面改到右栏顶部；侧栏底部换成服务器连接状态和设置入口 |
| D2 | 右栏：队列在上、歌词在下，两者同时显示，中间分隔线可以拖动（`panel-split`）；播放条的队列 / 歌词按钮分别开关两块 | 右栏 = 正在播放头部（封面、曲名、艺人 · 专辑、音质、独占）+ **歌词 \| 队列 页签**（默认歌词）。播放条的歌词按钮打开右栏并切到歌词页签，队列按钮打开右栏并切到队列页签；再点一次当前页签对应的按钮则关闭右栏。`panel-split` 不再使用（读到旧值时忽略，不报错）。`panel-width` 拖动保留 |
| D3 | 主页聚焦卡（Spotlight）背景是模糊封面（Electron `.hero-bg`） | 改成中性深灰色带（#1b1b21 → #121217 横向渐变），不再用封面 |
| D4 | 播放条始终显示封面 | 右栏打开时，播放条左侧不显示封面（只留曲名、收藏、音质、艺人 · 专辑） |
| D5 | 全屏播放器：页签 接下来播放 / 相关歌曲 / 歌词 | 主内容宽度 ≥ 1700 时三段式：左封面、中歌词（常驻）、右「接下来播放 / 相关歌曲」页签；更窄时保持现在的三页签 |
| D6 | 侧栏宽度可拖动（180-400，默认 210） | 保留拖动，默认改为 248；窗口宽度 < 1700 时侧栏收成 72 宽的图标条（拖动值保留，回到宽窗口时恢复） |

### 字号（逻辑像素，Inter + Noto Sans SC / JP，沿用现有的 `Fonts.family`）

| 用途 | 字号 / 字重 |
|------|-------------|
| 次要信息、时间戳、表头 | 12.5-13 / 400-500 |
| 正文、列表行标题 | 15 / 550-650 |
| 卡片标题 | 15-16.5 / 650-750 |
| 右栏曲名 | 24 / 780 |
| 区块标题（后接细线） | 26 / 780 |
| 列表页标题（专辑、曲目……） | 64 / 850 |
| 全屏播放器曲名 | 56 / 850 |
| 首页横幅标题 | 宽 / 中 / 窄窗口：64 / 52 / 44，字重 600，自然字距 |
| 专辑页标题 | 宽 / 中 / 窄窗口：72 / 56 / 44，字重 600，自然字距 |

**大标题的长度规则**：横幅和专辑标题最多两行，超出就省略。两行放不下时，依次尝试当前档位字号的 85%、70%、60%（取整，通常不小于 32，且绝不超过该档位起始字号）。不再使用固定 56px 的兜底，以免窄窗口长标题反而放大。文字局部纵向偏移对齐物理像素，不使用整体缩放。ui-snapshot `UI_SNAPSHOT_ONLY=typography` 覆盖短 CJK 标题、长日文与英文标题、三档窗口及浅色主题；封面和操作按钮尺寸不变。

### 圆角 / 间距 / 尺寸

- 圆角：封面 0（直角，杂志风；右栏和全屏大封面 12-14），按钮 20（胶囊），标签 5，卡片 / 面板 10-12。
- 间距：页边 40，区块之间 44-56，区块标题和内容之间 18。
- 图标 20（导航、播放条），线宽 1.7；按钮高 40，播放条控件热区 36。

### 外壳尺寸与断点（窗口逻辑宽度 W）

| 区域 | W ≥ 1700 | 1280 ≤ W < 1700 | W < 1280 |
|------|----------|-----------------|----------|
| 左导航 | 248（可拖动 180-400），带文字 | 72 图标条（歌单只显示封面） | 64 图标条 |
| 右栏 | 420（可拖动），常驻 | 372，常驻 | 默认收起，打开时作为覆盖层浮在主内容右侧 |
| 右栏封面 | 栏宽 - 48 | 248 | 248 |
| 播放条 | 高 92，三段 1fr / 820 / 1fr，进度条最长 760 | 高 84，1fr / 600 / 1fr | 高 80，1fr / 480 / 1fr |
| 首页横幅 | 封面 340、标题、右侧 520 宽曲目预览 | 封面 252，隐藏曲目预览 | 封面 220，隐藏曲目预览 |
| 首页「最近添加」 | 4 列 x 200 | 3 列 | 3 列 x 140 |

现有代码在 `m032.slint` 里有 `wide >= 1440`、`narrow <= 1040` 等断点，是按页面宽度判断的。新断点按**窗口宽度**判断，放在 `AppWindow` 里统一计算，向下传给各页面。

## 分阶段实施

每个阶段完成时都要满足：

- `cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace --exclude player --exclude app` 全部通过。
- 用 ui-snapshot 按 2300x1190、1600x900、1280x800 三档渲染，和终稿 PNG 并排检查。
- 在 `docs/TASKS.md` 的「UI 改版」一节打勾，并整理本阶段的 **[Win]** 验证项，在 Windows 上一次验证。
- 不丢功能：现有的点击、右键菜单、拖动、悬停、键盘操作都要保留。

### P0 准备：ui-snapshot 支持宽屏

- `tools/ui-snapshot`：增加 2300x1190、1600x900、1280x800 三档画布（缩放比 1），输出 `home-2300.png` 等文件。
- 假数据补齐：长标题（见上）、带 OP / ED 和多部关联作品的曲目、作品海报（2:3）、今日推荐 5 项、接着听 4 项。
- 可选：设置环境变量 `UI_SNAPSHOT_COVERS=<目录>` 时，从该目录读取真实封面（本地用 `prototypes/assets/covers/`，不进仓库）；没设置时沿用渐变假封面。

### P1 基础：Theme 和图标

- `theme.slint`：按上表补齐 token（`chrome`、`panel`、`accent-text`、`ok`、横幅色带），调整现有 token 的值，亮色同步。新增字号 token（`Type` global 或 `Theme` 里的 `font-*`）。
- `controls.slint` 的 `Icon`：用 `prototypes/_src/icons.svg` 的路径替换现有路径，线宽 1.7，圆头圆角。`<circle>` / `<rect>` 要换算成 path 的弧线命令。
  新增需要的种类：`expand`（全屏）、`speaker`（独占）、`lang`（翻译）、`minus`、`info`、`sliders`（歌单管理）、`list-plus`（加入队列）、`sort-desc`。
  传输按钮（播放、暂停、上一首、下一首、实心心形）继续用填充图标。
- 先在一个页面验证 Slint `Path` 对相对命令和弧线命令的支持，有问题就把路径预处理成绝对命令。
- **[Win]**：图标清晰度（100% / 150% 缩放）、亮暗两套主题的对比度。

### P2 外壳：左导航、右栏、播放条

- **左导航**（`app.slint` 的 sidebar、`NavItem`）：行高 42、图标 20、字号 15；当前项用 `raised` 底加 accent 色图标。
  歌单项改为 42 封面加两行文字。去掉底部当前封面（D1），底部换成服务器状态（主机名，有曲目总数就加上）和设置入口。< 1700 时收成图标条（D6）。
- **右栏**：新增 `NowPlayingPanel` 组件。头部是封面、曲名、艺人 · 专辑、音质标签、「独占 · bit-perfect」状态、收藏；下面是 歌词 | 队列 页签，复用 `LyricsPanel` / `QueuePanel` 的内容（D2）。
  歌词在剩余高度里垂直居中，上下用渐变 Rectangle 做渐隐；歌词工具条固定在底部。保留宽度拖动。< 1280 时改成覆盖层。
- **播放条**（`views.slint` 的 `PlayerBar`）：按上面的尺寸重排。右侧分三组：[独占 chip、睡眠 chip（显示剩余时间）] / [歌词、队列、全屏] / [音量]，组间 1px 竖线。
  右栏打开时左侧不显示封面（D4）。进度条居中，最长 760。
- 断点统一在 `AppWindow` 计算（见上表）。
- **[Win]**：
  - 2300、1600、1280 三档窗口宽度下的外壳。
  - 侧栏拖动和图标条切换。
  - 右栏页签和播放条按钮的联动、右栏宽度拖动和重启后保持。
  - 1280 下的覆盖层。
  - 歌词居中和渐隐。

### P3 首页

- **横幅**（`Spotlight`）：贴边铺满，用中性色带（D3）。左边封面 340；中间是四个页签、超大标题（长度规则见上）、艺人、元信息和音质、按钮；右边是 520 宽的曲目预览（带分隔线和「专辑详情 >」）。页签和现有行为一一对应。
- **区块标题**（`SectionHead`）：26/780，后面跟一条细线延伸到右边缘，右端放「查看全部 >」或筛选。
- **今日推荐 / 最近播放 / 接着听**（`HomeRowView`）：
  - 今日推荐：行高 80，64 的拼图封面，右箭头紧贴内容。
  - 最近播放：行高 64，相对时间（今天 23:37 / 昨天 / 10月27日）。
  - 接着听：一行 4 张卡片（封面 84、进度条、已播 / 总时长）。
- **最近添加**：网格，列数随宽度变化（4 / 3），每张卡片下面三行文字（标题、艺人、入库于）。
- **按作品漫游**（`WorkCardH`）：一行 5 张，2:3 海报 128x192，右侧依次是类型 · 年份、作品名（最多 3 行）、用途标签、收录数。
- **主题曲与插曲**：宽窗口下两栏。每行是封面 48、曲名 / 艺人、「◆ OP」标签、作品小海报 18x27 加作品名、时长、加入队列。
- **编年 / 某年专辑 / 歌单**：按新 token 调整样式，当前年份高亮并标出数量。
- **[Win]**：三档宽度下的首页；横幅长标题；各模块的点击、翻页、换一批、悬停播放。

### P4 专辑页和列表页

- **专辑头部**（`DetailHeader`）：封面 380；超大标题（长度规则）；艺人 24/650；元信息；作品胶囊（带 20x30 小海报和用途）；按钮组（播放、随机播放、收藏、加入歌单、更多）。
  头部右侧放发行信息块（类型、发行日期、厂牌、碟数、最高音质），数据来自现有的 `DetailInfo` / `FactRow`。
- **曲目表**（`TrackRowView`）：列为 # 44 / 标题 / 艺人 220 / 收藏 40 / 时长 64，行之间加分隔线。署名行、当前行（accent 浅底加音柱）、悬停态按终稿。
  「◆ OP」标签改成胶囊样式，有多部作品时带数量。**`TieupCards` 弹窗的交互不变**（悬停预览、移入保持、点击跳转），样式改成终稿：海报 72x108、作品名、译名、用途、类型 · 年份。
- **右侧信息栏**（`AlbumInspector`）：宽窗口下和曲目表并排（约 440 宽）。关联作品用 72x108 海报；后面是同艺人的其他专辑等。现有分组全部保留。
- **列表页**（`PageHeader`、`ListToolbar`、`CardGrid`）：页面标题 64 加数量；筛选栏控件高 40；已启用的筛选显示为可移除的 chip；网格每行 6 列左右。原型里的 A-Z 字母索引**不做**（不在 FEATURES 里）。
- **[Win]**：
  - 专辑页长标题、多碟专辑、OP / ED 悬停弹窗、关联作品点击。
  - 窄窗口下的「曲目 / 信息」页签。
  - 专辑、曲目、作品、系列各列表页。

### P5 全屏播放器

- `fullscreen.slint`：主内容宽度 ≥ 1700 时三段式（D5）。
  - 左边：封面 620、曲名 56、艺人 · 专辑、音质和独占标签、曲目信息入口。
  - 中间：歌词常驻，当前行 44、其他行 34 带翻译；顶部一行放「歌词 · 来源」和歌词工具（搜索、偏移 - 值 +、翻译、清除）。
  - 右边：440 宽的「接下来播放 / 相关歌曲」页签。
  背景纯深色 #0d0d11，底部播放条保留。更窄时保持现有的三页签布局，只换样式。
- **[Win]**：2300 和 1600 两档下的全屏播放器；歌词滚动、点击跳转、偏移、翻译；队列和相关歌曲的点击。

## 不做

- 封面取色、模糊封面背景、任何随封面变色的氛围效果（决策 6）。
- 原型里出现、但现有功能没有的东西：A-Z 字母索引、作品话数（服务端没有就不显示）、「本周播放次数」之类的统计。
- 新功能和数据接口改动。这一轮只改界面。
